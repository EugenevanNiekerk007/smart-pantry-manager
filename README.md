# Smart Pantry Manager

Smart Pantry Manager is an Android application developed in Java using Android Studio.

The purpose of the app is to help users keep track of ingredients they already have at home and find recipes they can make using those ingredients.

## Features

- Add pantry ingredients
- Edit existing ingredients
- Delete ingredients
- View all pantry items
- Store pantry data using SQLite
- Browse the recipe collection
- Add custom recipes
- View recipe details and cooking instructions
- View recipes that can be made with the ingredients available
- View recipes that are almost possible to make
- Save data when the app is closed and reopened

## Recipe Matching

The app checks the ingredients required for a recipe against the ingredients available in the pantry.

A recipe is only shown under Suggested Recipes when all the required ingredients are available in sufficient quantities.

The app also handles compatible measurements when comparing ingredient quantities.

## Built With

- Java
- Android Studio
- SQLite
- XML layouts
- RecyclerView
- Git and GitHub

## Running the App

1. Open the project in Android Studio.
2. Allow Gradle to sync.
3. Start an Android emulator or connect an Android device.
4. Click Run.
5. The Smart Pantry Manager app will open on the device.
